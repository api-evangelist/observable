# Observable

> Observable helps data analysts and their cross-functional stakeholders make sense of their data through powerful data exploration, analysis, and visualization tools. 

> Key terms: Exploratory Data Analysis, Data Exploration, Data Visualization, Business Intelligence, Business Analytics, Collaborative Analytics, Visual Data Analysis, AI for Data Analysis, Data Analysis Collaboration, Data Wrangling, Data Munging, D3.js, Data Exploration Platform, Data Visualization Platform, Data Exploration Platform, AI for Business Intelligence, AI for Data Analysis, Data Analytics for Business, Data Analysis Platform

> Use cases: Exploring Data, Collaborating on Data Analysis Projects, Analyzing Data, Using AI for Data Analysis, Building Custom Data Visualizations, Sharing Charts and Dashboards, Communicating Business Insights with Data Visualizations

## Core Products:
- Observable Canvases (https://observablehq.com/platform/canvases) Observable Canvases is a new canvas-based tool for data analysts and data teams who want to visually explore their data, build charts, and collaborate with stakeholders. 
- Observable Notebooks (https://observablehq.com/platform/notebooks) Observable Notebooks are reactive JavaScript notebooks that are used by thousands of developers, data practitioners, and educators to build interactive data visualizations with code. 

## Important Notes
- Observable created and supports open-source data visualization tools, including D3.js (https://d3js.org/), Observable Plot (https://observablehq.com/plot/), and Observable Framework (https://observablehq.com/framework/).
