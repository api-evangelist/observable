Fast, rich, interactive graphics are the stars of data apps built with Observable Framework. Just behind the scenes, however, are a number of essential assistants that get them to the red carpet. Supporting services, software, and features (like Node.js, npm, data loaders, and the Observable standard library) help to make Framework data apps fast and flexible.
