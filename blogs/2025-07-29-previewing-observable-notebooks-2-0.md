We’re excited to share a preview of the next generation of Observable Notebooks! Today’s technology preview release includes: Observable Notebook Kit - An open file format for notebooks, and accompanying open-source tooling for generating static sites Observable Desktop - A macOS desktop application for editing notebooks as local files, and with a radical new approach to AI You can learn more and download Observable Desktop by visiting the Notebooks 2.0 website .
